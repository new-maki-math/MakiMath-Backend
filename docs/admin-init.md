# 本地管理员初始化

先准备后端 `.env` 数据库配置，并在目标数据库中完成项目数据库结构初始化。配置中的数据库账号需要拥有用户表查询、锁定和插入权限。

在后端项目目录的交互式终端运行：

```powershell
pn run admin:init
```

命令会先显示实际连接的数据库、数据库用户和地址，确认无误后输入 `yes`。随后依次输入用户名、昵称和两次密码，密码不会回显。密码至少八个字符，UTF-8 编码后不得超过七十二字节。

用户名已经存在或数据库已有有效管理员时，命令会退出，不会覆盖密码或调整已有账号的权限。并发执行时会在事务中重新检查。按 Ctrl+C 可取消。

Node 读取 `.env` 时，当前进程中已设置的同名环境变量优先；请以命令显示的实际数据库为准。该命令不会创建数据库、执行结构脚本或启动服务。
